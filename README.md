# Omarchy Optimization

A set of scripts to debloat and optimize your [Omarchy](https://github.com/basecamp/omarchy) experience.

> ⚠️ Run `debloat.sh` first, then `install.sh`.

---

## Step 1 — Debloat

Removes opinionated default apps you probably don't need:

| Package |
|---------|
| signal-desktop |
| 1password-beta |
| 1password-cli |
| aether |
| spotify |
| libreoffice-fresh |
| typora |
| xournalpp |
| kdenlive |
| obsidian |

## Step 2 — Install

Installs lightweight alternatives and useful tools:

| Package | Description |
|---------|-------------|
| fish | Friendly interactive shell |
| nano | Simple terminal text editor |
| catnap | Minimal system fetch |
| linux-wifi-hotspot | Wi-Fi hotspot manager |
| dnsmasq | Lightweight DNS/DHCP server |
| hostapd | Access point daemon |
| pacman-contrib | Extra pacman utilities |
| zen-browser-bin | Privacy-focused browser |
| yazi | Blazing fast terminal file manager |

Also installs the **[latchdark theme](https://github.com/atif-1402/omarchy-latchdark-theme)** for a darker Omarchy look.
